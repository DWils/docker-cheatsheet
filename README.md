# Aide-mémoire Docker

Page HTML autonome (police, CSS et script inclus) récapitulant les commandes Docker essentielles :
conteneurs, images, options de `docker run`, build, filtrage, logs, `exec`, `inspect`, et les volumes
(nommés, anonymes, bind mounts, tmpfs).

## Utilisation

Ouvrir `docker-cheatsheet.html` dans un navigateur. Chaque commande peut être copiée d'un clic.

## Mise à jour

Le fichier est un simple fichier HTML/CSS/JS sans dépendance de build : l'éditer directement suffit.
